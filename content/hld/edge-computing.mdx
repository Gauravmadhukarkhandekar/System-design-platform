# Edge Computing

Moving computation closer to users for lower latency and better performance.

## The coffee shop analogy

<MetricTable
  title="Simple analogy"
  columns={['Model', 'What it means']}
  rows={[
    [
      'Traditional (Origin Server)',
      'Order coffee, barista ships it from headquarters across the country. Takes forever.',
    ],
    [
      'Edge Computing',
      'Coffee shops in every neighborhood. Your order is prepared at the nearest location. Fast and fresh.',
    ],
  ]}
/>

**Edge computing:** running code and storing data at locations geographically close to users, rather than in a centralized data center. Part of a CDN strategy for dynamic content.

## Key takeaways

<SummaryBox title="Key takeaways">
- Edge computing runs code close to users for low latency
- Great for authentication, A/B testing, geo-personalization
- Limited execution time and storage compared to origin
- Cloudflare Workers and Vercel Edge are popular choices
- Use edge for lightweight, latency-sensitive operations
</SummaryBox>
