# Parking Lot System

## Introduction

Designing a parking lot system is a classic LLD problem. You must model vehicles, parking spots, floors, and the logic for entry, exit, and finding a spot.

## Core Entities

- Vehicle: type (car, bike, truck), registration.
- ParkingSpot: type, availability, possibly floor.
- Floor: collection of spots.
- ParkingLot: floors, entry and exit gates, assignment logic.

## Key Operations

- Assign a spot on entry by vehicle type.
- Free the spot on exit.
- Find available spots by type.
- Optional: pricing, reservations.

## Summary

Model vehicles, spots, floors, and the lot; implement assign and free with clear interfaces.
